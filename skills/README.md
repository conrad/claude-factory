# Factory skills (control surface)

The live skill is **`.claude/skills/factory/SKILL.md`** — that location is
what makes `/factory` a slash command in Claude Code. This directory exists
for any future skills that aren't slash commands.

Subcommands: `new`, `pull`, `add-repo`, `status`, `approve`, `revise`,
`reject`, `resume` (see README.md quickstart and DESIGN.md §8).
